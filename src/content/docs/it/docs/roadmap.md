---

Vitrine 2 è una riscrittura completa di Vitrine 1. Il motore ha tutto ciò che serve per la prima
release; questa pagina mostra a che punto è ogni parte.

| Milestone | Stato |
| --- | --- |
| Integrazione nel desktop sotto le icone, su Windows 10 e 11 (anche 24H2 e successivi) | Fatto |
| Renderer: impaginazione, testo, SVG, sfumature, ombre, transizioni | Fatto |
| Vetro smerigliato (`backdropFilter`) e decorazioni del testo | Fatto |
| Runtime degli script e [`@vitrine/sdk`](https://github.com/vitrine-org/sdk) | Fatto, SDK 2.2.0 |
| Pacchetti, griglia e Modifica layout, con le finestre che si fanno da parte | Fatto |
| Metriche di sistema e gestione dell'energia | Fatto |
| Widget interattivi sotto le icone, inserimento di testo con `prompt()` | Fatto |
| Pannello di controllo con anteprime dal vivo, menu di Windows 11 | Fatto |
| Essentials (Conky), Vega e i quattro temi | Fatto |
| Dieci lingue dell'interfaccia e pacchetti localizzabili | Fatto |
| Catalogo dello [store](/it/packs/) e sito | Fatto |
| Store e ricerca dentro il pannello di controllo | In corso |
| Installer e prima release pubblica, 2.0.0 | In corso |

Segui i lavori su [GitHub](https://github.com/vitrine-org/vitrine).
